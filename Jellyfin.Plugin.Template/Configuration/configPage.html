There is nothing to configure yet. Settings appear on this page as the features that read them are built, and what is planned is on the milestones in the repository.

One setting will not appear here, and this is the place to say so rather than the release notes. The name of the discover library cannot be changed. The server builds the identity of every item under a library out of that name, so renaming it turns every title into a new one and leaves every favourite and every played mark on titles nobody can reach any more. The name is therefore fixed in the build, and changing it in a later version is treated as a breaking change rather than as better wording. docs/title-identity.md is the reading of the server that this comes from.
